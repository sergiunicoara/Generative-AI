# undeclared anywhere (not in requirements.txt, requirements-dev.txt, or
# pyproject.toml) -- the render scripts worked locally only because gTTS

# `clean-install` job installs requirements.txt alone specifically to prove
# the real runtime/API dependency set is complete, and requirements-dev.txt is
# installed by every test job. Video rendering is neither -- it's an
# on-demand authoring step, not something the app or its test suite imports.
#
# Install with:  pip install -r requirements-presentation.txt
#
# Also required on PATH, not pip-installable: ffmpeg + ffprobe (verified
# present in this environment: /c/ffmpeg/bin).
